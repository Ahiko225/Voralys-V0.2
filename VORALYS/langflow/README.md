# langflow/ — Flows exportés

Un sous-dossier par agent (ex: langflow/AG01/) contenant l'export du flow Langflow versionné.
Langflow reste le runtime d'exécution ; ce dossier est la copie de sauvegarde/versioning
(source de vérité = GitHub, cf. section "GitHub et Langflow" de la fiche d'architecture).
